# Deepwork ID

Spina dorsale dell'ecosistema: account unico, multi-tenant, abbonamenti.
Prerequisito (Fase 0) di tutte le app verticali.

Requisiti chiave (dal fondatore):
- Profilo personale unico per tutte le app dell'ecosistema e per le
  funzionalità a pagamento (entitlement).
- Multi-tenant rigoroso: isolamento totale dei dati tra organizzazioni
  (clienti spesso concorrenti tra loro).
- Registrazione + login Google (ideale) con verifica autorizzazioni.
- Sostituisce le password in chiaro di Deepwork.
- Base per la "modalità tour di prova" per utenti senza credenziali.
